# SoukouMincho Font Notice

This project uses SoukouMincho, also known as 装甲明朝, as a local web font.

- Distribution page: https://flopdesign.booth.pm/items/1028555
- License stated by distributor: SIL Open Font License 1.1
- Bundled license file: `LICENSE_OFL.txt`
- Bundled readme file: `ReadMe.txt`
- Upstream derivative source stated by distributor: Source Han Serif
- Local source font: `SoukouMincho.ttf`
- Local generated web font: `SoukouMincho-subset.woff2`

`SoukouMincho-subset.woff2` is generated from `SoukouMincho.ttf` using the
manual corpus in `soukou-mincho-corpus.txt`.

The bundled `LICENSE_OFL.txt` defines what a Reserved Font Name is, but does not
declare a concrete Reserved Font Name for SoukouMincho. When replacing the source
font, keep the license file distributed with the font archive and re-check
whether any Reserved Font Name declaration is present.
